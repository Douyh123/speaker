# 讲明白

> 随机抽一个专业名词 → 限时查资料、做纸质笔记（**不许问 AI**）→ 计时结束，把它讲给别人听 → 回来自评存档。

一个纯前端的自我训练工具。练的不是「知道这个词」，而是「能把它讲明白」。所以它围绕**输出**设计，而不是围绕**记忆**设计。

## 核心循环

```
[idle 首页] ──抽词──▶ [ready 准备] ──开始──▶ [running 计时中]
     ▲                    │                      │
     │                 重抽(不限)              提前结束
     │                    │                      ▼
     │                    └────────────────▶ [review 复盘]
     │                                           │
     └─────────────── 存档 ───────────────────────┘
```

| 阶段 | 你看到什么 | 你做什么 |
|---|---|---|
| `ready` | 词 + 分类，**不含任何释义** | 摊开纸笔、开搜索窗口 |
| `running` | 大号倒计时 + 词常驻 | 在别的标签页查资料、手写笔记 |
| `review` | 自评 + 写要点 | 讲给别人听，然后回来填 |

## 为什么不能用 AI

这是产品的**硬约束**，也是它唯一的设计前提：整个流程里不出现任何 AI 生成内容。

它反向约束了很多细节——

- 计时结束前，页面上绝不出现词义、提示、释义或任何查百科外链。
- 词条的释义字段只在复盘之后可见。
- 不做内置词典、不做「一键解答」。

你要的是一次真正的检索、理解和复述。有捷径，这个练习就没意义了。

## 功能

- **抽词**：三种模式切换——优先未讲过（默认，按完成次数降权）、纯随机、待复习池。
- **计时**：默认 15 分钟，用绝对时间戳计算，切后台、休眠、误关标签页都能正确恢复。
- **断点恢复**：计时中途关掉页面，重新打开接着走；离开期间已超时的，直接进复盘。
- **复盘**：自评 + 写「下次要讲到的点」+ 标记「待复习」，选择是否写下承诺。
- **记录与统计**：时间线、按词条聚合、统计三个标签，含 90 天热力图与分类覆盖率、连续练习天数。
- **词库管理**：可视化增删改词条（词 / 分类 / 别名 / 备注 / 启用开关），支持搜索、按分类筛选、批量启停。
- **备份**：导出 / 导入 JSON，支持「合并」与「覆盖」两种方式；距上次备份超过 14 天会在首页提醒。

## 技术栈

原生 JS，不引框架。这个体量用 React / Vue 是负重。

- 构建：**Vite + `vite-plugin-singlefile`**，产物是**一个自包含的 `dist/index.html`**，零运行时依赖，双击即用（约 59 KB，gzip 21 KB）。
- DOM：自写的 `h()` 构建器，**全程不用 `innerHTML`** —— 词条文本是用户可编辑的，是 XSS 的入口。
- 存储：`localStorage`，key 带版本号后缀（`speaker.terms.v1` 等），方便日后结构迁移。
- 计时：绝对时间戳（`remainingMs`）而非 `setInterval` 累加 —— 后台标签页会被节流到约 1 次/分钟，累加会漂。
- 数据形态：全是结构化小文本，没有二进制资源，所以**不需要 IndexedDB**，5 MB 额度绰绰有余。

## 快速开始

```bash
npm install
npm run dev        # 开发：带热更新
npm run build      # 交付：产出 dist/index.html
npm test           # 逻辑自检（纯 Node，不需要浏览器）
```

日常使用走本地静态服务而不是 `file://` —— 部分浏览器会把 `file://` 当不透明 origin，写进 `localStorage` 下次读不到。附了 `start.bat`：

```
python -m http.server 8080
start http://localhost:8080
```

## 测试

`npm test` 跑的是 `test/logic.mjs`：一个不依赖 DOM 的断言脚本，覆盖抽词权重、计时换算、streak 口径、热力图周对齐、备份合并语义和存储层。改动这些逻辑后先跑它。

## 数据

数据只存在你自己的浏览器里，不上传任何服务器。

- 清缓存、换电脑会丢，**靠备份**。
- 导出是一个 JSON 文件，装下全部数据：词库 + 记录 + 设置。
- 可以放网盘或换台机器再导入回来；导入支持合并（两边都留，同一条以备份为准）或覆盖。

## 内置词库

首版是 80 个心理学专业名词，分 5 类：社会心理学、认知偏差、情绪与动机、人格与发展、经典实验。

词库自带标记，可自行扩充。内置词条**只能停用、不能删** —— 应用每次启动会把缺失的内置词条补回来，这样以后往内置词库加词时，老用户能自动拿到。要彻底删掉，可以用「恢复内置词库」重置或直接删掉自己建的那些。
